# Velora — موقع فوتوجرافر (Ronadisa Al-Sayed)

موقع احترافي لاستوديو **Velora** يشمل: صفحة رئيسية، عن الاستوديو، معرض أعمال، الخدمات، صفحة تواصل، واستمارة حجز/تسجيل بيانات تُخزَّن مجانًا على **Firebase Firestore**، بالإضافة إلى لوحة تحكم خاصة (Admin Dashboard) محمية بكلمة مرور تقدري منها:

- تشوفي كل المسجلين وتتذكري أعياد الميلاد القادمة، مع تصدير القائمة كملف CSV/Excel.
- تضيفي وتحذفي صور معرض الأعمال (Portfolio) مباشرة من المتصفح، من غير أي كود.
- تعدّلي الإيميل والتليفون، وتضيفي/تحذفي روابط السوشيال ميديا (إنستجرام، فيسبوك، واتساب...) وتظهر تلقائيًا في كل صفحات الموقع.

الموقع يدعم اللغتين **العربية والإنجليزية** (زر التبديل AR/EN في أعلى كل صفحة)، ومبني بألوان الهوية:
`#fffefb` أوف وايت · `#e6e1d6` لايت اورانج · `#afbb9c` جراي جرين · `#c6a585` جراي اورانج.

كل الأدوات المستخدمة **مجانية 100%** (GitHub Pages للاستضافة + Firebase Spark Plan للقاعدة).

## 2. تجهيز قاعدة البيانات المجانية (Firebase)

هذه الخطوات تُعمل **مرة واحدة فقط**، ومجانية تمامًا (خطة Spark المجانية تكفي آلاف المسجلين شهريًا).

1. افتحي [console.firebase.google.com](https://console.firebase.google.com) وسجّلي دخول بحساب Google.
2. اضغطي **Add project** واختاري اسمًا مثل `velora-studio` ثم أكملي الخطوات (يمكنك تعطيل Google Analytics، غير ضروري).
3. من داخل المشروع، اضغطي على أيقونة **</>  (Web)** لإضافة تطبيق ويب، وسمّيه `Velora Website`. **لا تحتاجي Firebase Hosting** — سنستخدم GitHub Pages.
4. بعد الإنشاء، ستظهر لك قطعة كود فيها object اسمه `firebaseConfig` — هذا هو المطلوب. افتحي ملف:
   `assets/js/firebase-config.js`
   واستبدلي كل قيمة فيها `REPLACE_ME...` بالقيمة المطابقة من الكونسول (apiKey, authDomain, projectId, storageBucket, messagingSenderId, appId).
5. من القائمة الجانبية: **Build → Firestore Database → Create database**. اختاري **Start in production mode** ثم اختاري أقرب موقع سيرفر (مثلاً `eur3` أو `nam5`).
6. بعد إنشائها، روحي لتبويب **Rules** بالأعلى، وامسحي المحتوى الموجود، ولصقي بدلًا منه محتوى ملف `firestore.rules` الموجود في هذا المشروع بالكامل، ثم اضغطي **Publish**.
   > هذه القواعد تسمح لأي زائر بإرسال استمارة الحجز، لكنها **تمنع أي شخص من قراءة أو رؤية القائمة إلا أنتِ** بعد تسجيل الدخول. القواعد الحالية بقت تشمل كمان صور المعرض (`portfolio`) وبيانات التواصل (`settings`) — لو سبق ولصقتي نسخة أقدم، لازم تلصقي هذا الإصدار الجديد وتضغطي Publish تاني.
7. من القائمة الجانبية: **Build → Authentication → Get started**. من تبويب **Sign-in method**، فعّلي **Email/Password**.
8. من تبويب **Users** بجانبه، اضغطي **Add user**، وضعي إيميلك وكلمة مرور قوية خاصة بيكِ — هذا هو حساب تسجيل الدخول للوحة التحكم (`login.html`)، ولن يستطيع أي شخص آخر الدخول إلا بهذا الإيميل وكلمة المرور.

بهذا تكون قاعدة البيانات جاهزة تمامًا ومجانية.

## 3. رفع الموقع على GitHub ونشره مجانًا (GitHub Pages)

1. لو معك حساب GitHub بالفعل تمام، لو لأ اعملي حساب مجاني على [github.com](https://github.com).
2. اضغطي **New repository**، وسمّيه مثلًا `velora-website`، واختاري **Public** (مطلوب public في الخطة المجانية عشان GitHub Pages يشتغل)، **لا تضيفي** README أو .gitignore من الموقع لأننا جهزناهم بالفعل. اضغطي **Create repository**.
3. GitHub هيوريكي أوامر تحت عنوان "…or push an existing repository from the command line" — هي شبيهة بالتالي (استبدلي USERNAME باسم حسابك):

   ```bash
   git remote add origin https://github.com/USERNAME/velora-website.git
   git branch -M main
   git push -u origin main
   ```

   شغّلي هذه الأوامر من داخل مجلد المشروع (فولدر `velora-website` بعد فك الضغط عن الملف المرسل لكِ).
4. بعد الرفع، من صفحة الريبو على GitHub: **Settings → Pages**. تحت **Build and deployment**، اختاري **Source: Deploy from a branch**، والفرع **Branch: main** والمجلد **/(root)**، ثم **Save**.
5. بعد دقيقة أو دقيقتين، هيظهر لكِ رابط الموقع الجاهز بالشكل:
   `https://USERNAME.github.io/velora-website/`
   شاركي هذا الرابط مع عميلاتك 🎉

> **ملاحظة أمان:** صفحة `login.html` و`admin.html` موجودة على نفس الرابط العام (كل ملفات GitHub Pages عامة)، لكن **بياناتك محمية فعليًا بقواعد Firestore** — لا يستطيع أي شخص فتح `admin.html` ورؤية أي بيانات بدون تسجيل الدخول بحسابك. فقط لا تنشري رابط `/admin.html` في مكان عام.

## 4. التحكم في المحتوى من لوحة التحكم (Admin Dashboard)

بعد تسجيل الدخول على `login.html`، هتلاقي في `admin.html` ثلاث لوحات (روابط سريعة فوق الصفحة):

- **Manage Portfolio:** اكتبي عنوان للصورة، اختاري الفئة (بورتريه / تصوير شارع / تحريري / أخرى)، اختاري الصورة من جهازك واضغطي **Add to Gallery**. الصورة بتتصغّر وتتضغط أوتوماتيك (من غير ما تحتاجي تعدليها بنفسك) وتُخزَّن مباشرة في قاعدة البيانات المجانية (من غير الحاجة لخدمة تخزين صور مدفوعة). تظهر فورًا في صفحتي `portfolio.html` و`index.html`. تقدري تحذفي أي صورة بزرار **Delete** تحت كل صورة.
- **Contact & Social Links:** غيّري الإيميل والتليفون واضغطي **Save**، وأضيفي روابط إنستجرام/فيسبوك/واتساب/تيك توك من نفس اللوحة — بتظهر تلقائيًا في فوتر كل صفحة وفي صفحة "تواصل معنا"، من غير الحاجة لتعديل أي كود.
- **Contacts & Bookings:** نفس لوحة المسجلين والحجوزات اللي شرحناها فوق.

طالما شغالة من اللوحة، مفيش داعي تعدّلي كود لأي حاجة من دول. لو حبيتِ تعدّلي نصوص ثابتة تانية (زي السلوجن أو وصف الخدمات)، هي موجودة في ملف `assets/js/i18n.js`.

- **النصوص بالعربي أو الإنجليزي:** كل نصوص الموقع الثابتة موجودة في ملف واحد فقط: `assets/js/i18n.js`، منظمة على شكل `"key": "النص"` — تقدري تعدّلي أي نص من غير التأثير على شكل الموقع.

## 5. حدود الخطة المجانية (Free Tier)

- **Firebase Firestore (Spark – مجاني للأبد):** حتى 1 جيجابايت تخزين، وحتى 50,000 عملية قراءة و20,000 عملية كتابة يوميًا. بيانات استمارة الحجز صغيرة جدًا، فهذا يكفي آلاف العميلات شهريًا بدون أي تكلفة.
- **GitHub Pages:** استضافة مجانية بالكامل للمواقع الثابتة مثل هذا الموقع.
- لو حبيتِ لاحقًا بديل أبسط بدون Firebase، يوجد خيار مجاني آخر باستخدام **Google Sheets + Google Apps Script** (تسجيل البيانات مباشرة في جوجل شيت)، لكن Firebase الحالي أقوى وأكثر أمانًا لأنه يحمي بياناتك بتسجيل دخول فعلي.

## 6. تشغيل الموقع محليًا للتجربة (اختياري)

لو حابة تشوفي الموقع على جهازك قبل الرفع:

```bash
cd velora-website
python3 -m http.server 8080
```

ثم افتحي `http://localhost:8080` في المتصفح. (استمارة الحجز ولوحة التحكم لن تعملا فعليًا إلا بعد إكمال خطوات Firebase أعلاه).
